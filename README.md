# 🌪️ StormShield AI

AI-powered emergency response platform for disaster risk reduction.

## 🎯 Features
- Flood prediction alerts
- Safe evacuation routes (GPS)
- AI emergency chatbot (Gemini)
- Damage reporting with AI image analysis
- SOS emergency button
- Real-time evacuation center locator
- Weather forecast integration

## 🛠️ Tech Stack
- **Frontend:** Vanilla HTML + CSS + JS (multi-page)
- **Backend:** Supabase (Auth, DB, Storage, Realtime, Edge Functions)
- **AI:** Google Gemini Flash (free tier)
- **Maps:** Leaflet + OpenStreetMap + OSRM (free)
- **Weather:** Open-Meteo (free)
- **Hosting:** Netlify
